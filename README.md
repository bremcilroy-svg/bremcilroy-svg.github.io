# Bre McIlroy — Creative & Professional Portfolio

A static portfolio for GitHub Pages. No installation or build tools are needed.

## Publish the update

1. Extract this ZIP on your phone or computer.
2. Open https://github.com/bremcilroy-svg/bremcilroy-svg.github.io and select the main branch.
3. Choose Add file (+) > Upload files. Select the extracted website files, including index.html, style.css, site.js, all other HTML pages, favicon.svg, and both images. Upload the files directly beside the existing index.html, rather than uploading the ZIP or adding a new enclosing folder.
4. Commit changes to main. Files with matching names will update; the new pages will be added.
5. Wait for the Pages deployment to finish, then visit https://bremcilroy-svg.github.io/ and refresh.

This package does not alter GitHub Pages settings. If your site already publishes from main and the root folder, keep those settings. GitHub's upload instructions: https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository
